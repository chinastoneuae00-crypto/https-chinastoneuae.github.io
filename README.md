# China Stone Construction Website

A responsive one-page construction company website inspired by the supplied reference image.

## Files
- index.html — complete page structure/content
- style.css — responsive design and styling
- script.js — mobile navigation

## Run
Open `index.html` directly in Chrome/Edge, or use VS Code + Live Server.

## Customize
1. Replace the Unsplash image URLs in `index.html` with your own project photos.
2. Change company name, phone, email and address.
3. Replace the text-logo with your actual PNG/SVG logo.
4. Add real project/news pages or connect the quote form to your backend.

The design is responsive for desktop, tablet and mobile.
